# Product vision

BrewFocus should make starting deep work take a few seconds.

The user should not need to understand productivity terminology, profiles, blocklists, or automation rules. They should understand: “I need to concentrate hard, so I’ll order an Espresso.”

## Core principles

- The coffee changes restriction level; it is not merely decoration or a timer preset.
- Safety beats strictness. Never destroy work or terminate apps blindly.
- The product tells the truth about what macOS can enforce.
- The default experience is local, private, native, and calm.
- History should feel like a satisfying shelf of completed work, not an enterprise dashboard.

## Current prototype outcome

A user can choose a coffee by the amount of freedom they want to retain, complete the matching fixed-length session, and see that specific cup on a local shelf. Latte keeps everything available, Cappuccino removes selected distractions, and Americano and Espresso narrow access to essential apps.

## Current non-goals

Custom durations and recipes, website blocking, Focus mode automation, cloud sync, accounts, subscriptions, analytics, themes, achievements, and cross-platform support.
