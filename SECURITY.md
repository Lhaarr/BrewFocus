# Security Policy

BrewFocus is pre-release software and is not a security boundary. Only the latest code on the default branch is currently supported.

## Reporting a vulnerability

Do not disclose a vulnerability in a public issue. Use GitHub's private vulnerability reporting for the repository. If private reporting is unavailable, contact a maintainer through the contact method on their GitHub profile and share only enough information to establish a private channel.

Include the affected platform and version, reproduction steps, expected impact, and whether the issue can leave apps hidden or Screen Time shields active.
